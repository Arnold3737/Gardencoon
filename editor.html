🔑 Подключение к GitHub

Редактор работает прямо в браузере и сохраняет изменения через GitHub API. Нужен токен с правом Contents: Read & Write.

Создайте на github.com/settings/tokens → Fine-grained → репозиторий Gardencoon → Contents = Read & Write.

Токен хранится только в localStorage вашего браузера. Никуда не отправляется, кроме GitHub API.
