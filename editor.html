🔑 Введите GitHub токен

Этот редактор работает прямо в браузере и публикует изменения через GitHub API. Нужен персональный токен с правом Contents: Read & Write.

Создайте токен на github.com/settings/tokens (Fine-grained, репозиторий Gardencoon, Contents = Read & Write).

Токен хранится только в этом браузере (localStorage). Никуда не отправляется кроме GitHub API.
