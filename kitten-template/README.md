# 🐱 Добавление нового котёнка на сайт

Инструмент для публикации новой карточки котёнка на gardenstatecoon.com
**одним действием**. Никаких знаний кода не нужно.

---

## ⚡ Самый простой способ (рекомендуется)

В корне репозитория есть готовый запускатор:
- **Windows:** `add-kitten.bat`
- **Mac:** `add-kitten.command`

### Что делать каждый раз, когда появился новый котёнок:

1. Создайте **папку** где угодно на компьютере (например, на рабочем столе).
   Назовите её именем котёнка — `nova`, `willow` и т.п.
2. Положите в неё **1–4 фотографии** котёнка (`.jpg`/`.png`/`.webp`)
   и, по желанию, **одно видео** (`.mp4`/`.mov`).
   Первое фото по алфавиту (`01.jpg`, `02.jpg`…) станет главным.
3. **Перетащите эту папку мышкой прямо на `add-kitten.bat`**
   (на Windows). На Mac — дважды кликните `add-kitten.command`
   и перетащите папку в открывшееся окно.
4. Программа задаст несколько вопросов **на русском** (имя, пол, окрас,
   статус, описание). Отвечайте и жмите Enter. Для родителей можно просто
   жать Enter — подставятся значения по умолчанию.
5. Готово. Карточка обработает фото, создаст страницу и **сама опубликует**
   всё на сайт. Сайт обновится через **~1 минуту**.

> Заполнять JSON-файл вручную **не нужно** — программа спросит всё сама
> и создаст `kitten.json` в папке котёнка автоматически.

---

## Что делает программа за вас

- 📸 обрезает каждое фото в 7 размеров-форматов (AVIF/WebP/JPG × 640/1024/1920)
- 🎬 копирует видео (если оно есть)
- 📝 создаёт страницу `kitten-detail-N.html` со всеми SEO-мета, JSON-LD, Open Graph
- 🔄 добавляет карточку на `kittens.html` и обновляет каталог
- 🗺️ дописывает адрес в `sitemap.xml`
- 📤 делает git commit + push в ветку `main`
- 🚀 GitHub Pages автоматически выкладывает сайт за ~1 минуту

## Первоначальная настройка (один раз)

1. Установите **Node.js** — [nodejs.org](https://nodejs.org) (кнопка LTS).
2. В папке репозитория один раз выполните `npm install`
   (это подтянет библиотеку обработки фото `sharp`).
3. Убедитесь, что `git push` проходит без запроса пароля
   (GitHub Desktop, или `gh auth login`, или SSH-ключ).

Путь к репозиторию настраивать **не нужно** — `add-kitten.bat`
и `add-kitten.command` лежат в корне репозитория и находят его сами.

## Поля, которые спросит программа

| Вопрос          | Обязательно | Пример                                    |
|-----------------|-------------|-------------------------------------------|
| Имя котёнка      | ✅          | `Nova`                                    |
| Пол              | ✅          | `м` или `ж`                               |
| Окрас            | ✅          | `Silver Shaded`                           |

| Мать (имя/опис.) | ⬜          | Enter = `Willow`                          |

## Способ для опытных (через папку-шаблон)

Если хотите подготовить данные заранее без вопросов:
1. Скопируйте папку `kitten-template`, переименуйте в имя котёнка.
2. Откройте `kitten.json` в блокноте и заполните поля.
3. Положите рядом фото/видео.
4. Запустите корневой `add-kitten.bat`, перетащив на него эту папку
   (программа увидит готовый `kitten.json` и вопросов задавать не будет).

Пример `kitten.json`:
```json
{
  "name": "Nova",
  "gender": "Female",
  "color": "Silver Shaded",
  "status": "available",
  "description": "Текст описания характера котёнка...",
  "healthTesting": "Health-screened parents from registered lines; examined by our veterinarian.",
  "sire": { "name": "Hudson", "title": "Brown Classic Tabby · Registered lines · Health-screened" },
  "dam":  { "name": "Willow", "title": "Blue Smoke · Registered lines · Health-screened" }
}
```

## Режимы запуска (из терминала)

- **Обычный** — публикует всё:
  `node scripts/add-kitten.js C:\путь\к\папке`
- **Dry-run** — ничего не меняет, только показывает план:
  `node scripts/add-kitten.js C:\путь\к\папке --dry-run`
- **Без пуша** — делает локальные изменения и коммит, но не пушит:
  `node scripts/add-kitten.js C:\путь\к\папке --no-push`

---

## Если что-то пошло не так

- **`scripts\add-kitten.js не найден`** — `add-kitten.bat` должен лежать
  в корне репозитория рядом с папкой `scripts`.
- **`В папке нет фотографий`** — положите фото в папку котёнка.
- **`sharp not found`** — выполните `npm install` в папке репозитория.
- **Ошибка `git push`** — войдите в GitHub (GitHub Desktop, `gh auth login`
  или SSH-ключ).
- **Опечатка в карточке** — отредактируйте созданные файлы вручную и
  сделайте ещё один коммит, либо откатите последний:
  `git reset --hard HEAD~1` и запустите программу заново.

## Советы по фото

- **Первое фото** (по алфавиту — `01.jpg`, `02.jpg`…) станет главным:
  оно появится в превью на `kittens.html`, в hero карточки и в Open Graph.
- Оптимально: исходник **≥1920px** по ширине, соотношение ~4:3 или 16:9.
- Чем больше исходник — тем лучше AVIF/WebP. Программа уменьшит, но не увеличит.
